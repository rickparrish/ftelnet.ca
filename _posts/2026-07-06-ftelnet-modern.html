I've received a few emails about fTelnet-Modern, so figured it might be good to share some of the questions/answers here:

  • How do I get fTelnet-Modern?  It's available on Tom Swartz's GitHub repo here: https://github.com/comicslut-png/fTelnet-Modern
  • Will the embed wizards be updated to use fTelnet-Modern?  Not the existing embed wizards, but if Tom creates a new embed wizard then I'm happy to help with an fTelnet subdomain (eg maybe embed-modern.ftelnet.ca)
  • Can I use the public proxies with fTelnet-Modern?  Yes, the public proxies will work fine with fTelnet-Modern.
  • Will you implement any of the fTelnet-Modern features in fTelnet "classic"?  Possibly, but probably not.  It's not that I don't think the new features are awesome and worthwhile to backport, but I don't have the time at the moment, and it would just be a duplication of effort.  That said, after Tom let me know about the fork I did a quick/hacky backport of the zmodem code to see if it would work in the "classic" codebase, and it only took a few minor tweaks, so if any feature is backported that's the most likely to be (I didn't implement the transfer dialog or auto-start feature, so still a fair bit of work needed, but nothing compared to the massive effort Tom undertook to get zmodem working in the first place)

If this is the first you're hearing about fTelnet-Modern, then I suggest you click the GitHub link above to take a look!
